# 辛口道場

League of Legends の Riot ID を入れると、直近20試合を集計して、

1. **解析** — 6つの軸(レーン戦・集団戦・視界・生存・オブジェクト・安定感)を100点満点で採点する
2. **自己紹介** — 成績から「俺はこういうプレイができるぜ」という強気な自己紹介を組み立てる
3. **辛口評価** — 評価役の「仮想らいじん」が、自己紹介のひとつひとつに数字でツッコミを入れ、総合評価(S〜D)・称号・次の宿題を出す

という流れで遊ぶ、個人用のページです。同じリポジトリの「つぎの一作」とは別物で、GitHub Pages には公開されません(`npm run build` の対象外)。自分のPCで開発サーバーを立てて使います。

## 使い方

```bash
npm install
npm run lol      # http://127.0.0.1:5174 で開く
```

APIキーがなくても、画面の「サンプル(架空のプレイヤー)で試す」から5人ぶんのデータで一通り遊べます。

### 自分の Riot ID で試す

1. [Riot Developer Portal](https://developer.riotgames.com/) に自分の Riot アカウントでログインし、APIキーを発行します。開発用キー(Development API Key)は24時間で切れるので、遊ぶ日に発行し直します。
2. `lol/.env.example` を `lol/.env.local` にコピーし、`RIOT_API_KEY=` のあとにキーを書きます(`*.local` は `.gitignore` 済みなので、コミットされません)。
3. `npm run lol` を起動し直し、「名前#タグ」(例: `なまえ#JP1`)を入れて「解析する」を押します。

昔の「サモナーネーム」は廃止され、いまは Riot ID(名前#タグ)で検索します。

## 守っていること

- **実在の人に迷惑をかけない。** 「仮想らいじん」は実在の配信者をモチーフにした非公式のパロディです。ご本人の写真・ロゴ・音声・実際の発言や口ぐせは使わず、文章はすべて成績の数字から組み立てたテンプレートです。評価の見出しとフッターに、非公式で自動生成だと毎回表示します。名前を出したくなったら、`src/labels.ts` の `CRITIC_NAME` と `CRITIC_CALL` を書き換えるだけで別のキャラクターになります。
- **辛口にするのはプレイの内容だけ。** 人格・容姿・属性に触れる文は置いていません。最後の「次の宿題」は具体的な助言にしています。
- **公開しない・広めない。** 開発サーバーは `127.0.0.1` にだけ開き、共有ボタンはなく、ページは `noindex` です。自分のアカウントで遊び、結果をご本人の発言であるかのように広めたり、ほかの人をからかう目的で使ったりしないでください。
- **APIキーをブラウザに渡さない。** キーは開発サーバー(Node 側の `server/`)だけが持ち、ブラウザには本人の成績だけを抜き出した結果を返します。ほかの9人の情報は画面に届きません。
- **Riot API を叩きすぎない。** 同じIDの結果は5分間メモリに持ち、回数制限(429)には待ってからやり直します。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/types.ts` | サーバーと画面の両方が使う型(`PlayerData` / `MatchStat`) |
| `server/riot.ts` | Riot API を呼び、1試合を本人の成績だけに絞る(Node 専用) |
| `server/plugin.ts` | 開発サーバーに `/api/player` と `/api/status` を足す Vite プラグイン |
| `src/analyze.ts` | 6軸の採点と、強み・弱みの判定 |
| `src/intro.ts` | 自己紹介の組み立て |
| `src/review.ts` | 辛口評価の組み立て |
| `src/sample.ts` | サンプル(架空のプレイヤー)5人ぶんの試合データ |
| `src/main.ts` / `src/style.css` | 画面(描画はここだけ) |

テストはルートの `tests/lol-*.test.ts` にあり、`npm test` でまとめて走ります。

## 採点の仕組み

- ロールごとに「悪い〜良い」の目安を置き、あいだを直線で 0〜100 点にします(`analyze.ts` の `BENCH`)。厳密な統計ではなく、ふつうなら50点前後になるように置いた値です。CS・視界・ダメージ割合などロールで基準が変わる項目は、メインロールの試合だけで見ます。サポートはCSを採点しません。
- 総合点は6軸の平均が9割、勝率が1割です。80点以上がS、67点以上がA、54点以上がB、41点以上がC、それ未満がDです。
- 自己紹介は、はっきり出ている強みから最大3つ。足りないぶんは弱みを強気に言い換えて埋め、評価役がそれを数字で崩します。強みは認めたうえで、関係する弱みがあれば「ただし」を足します。
- 文章は Riot ID から決まる種で選ぶので、同じ人なら同じ結果になります。「言い直してもらう」で別の言い回しに変わります。
- AI(LLM)は使っていません。入れる場合は、APIキーをブラウザに置かず `server/` 側を経由させてください。
