# 辛口道場

League of Legends の Riot ID を入れると、直近20試合を集計して、

1. **解析** — 6つの軸(レーン戦・集団戦・視界・生存・オブジェクト・安定感)を100点満点で採点し、対面との差、デスの時刻と場所、条件別の勝率(サイド・試合の長さ・時間帯・連戦など)までくわしく出す
2. **自己紹介** — 成績から「俺はこういうプレイができるぜ」という強気な自己紹介を組み立てる
3. **辛口評価** — 評価役の「仮想らいじん」が、自己紹介のひとつひとつに数字でツッコミを入れ、総合評価(S〜D)・称号・次の宿題を出す

という流れで遊ぶ、個人用のページです。同じリポジトリの「つぎの一作」とは別物で、GitHub Pages には公開されません(`npm run build` の対象外)。自分のPCで開発サーバーを立てて使います。

## 使い方

```bash
npm install
npm run lol      # http://127.0.0.1:5174 で開く
```

APIキーがなくても、画面の「サンプル(架空のプレイヤー)で試す」から5人ぶんのデータで一通り遊べます。

### 自分の Riot ID で試す

1. [Riot Developer Portal](https://developer.riotgames.com/) に自分の Riot アカウントでログインし、APIキーを発行します。開発用キー(Development API Key)は24時間で切れるので、遊ぶ日に発行し直します。
2. `lol/.env.example` を `lol/.env.local` にコピーし、`RIOT_API_KEY=` のあとにキーを書きます(`*.local` は `.gitignore` 済みなので、コミットされません)。
3. `npm run lol` を起動し直し、「名前#タグ」(例: `なまえ#JP1`)を入れて「解析する」を押します。

昔の「サモナーネーム」は廃止され、いまは Riot ID(名前#タグ)で検索します。

## 守っていること

- **実在の人に迷惑をかけない。** 「仮想らいじん」は実在の配信者をモチーフにした非公式のパロディです。評価の見出しとフッターに、非公式で自動生成だと毎回表示します。評価の中身(数字へのツッコミ)は成績から組み立てたもので、ご本人の発言ではありません。
- **口ぐせは、確かめられたものだけ。** ご本人の言い回しを評価文の前後に差し込みます(`src/phrases.ts`)。コードに入れるのは出典を確かめられたものだけで、出典をコメントに書いています。言っていないことを「言った」ことにしないためです。自分で聞いたことのある言い回しは、手元の `public/local/phrases.json` に足せます(下の「写真・ロゴ・口ぐせを足す」)。
- **写真とロゴは公開リポジトリに入れない。** このリポジトリは公開されているので、ご本人の写真やロゴをコミットすると、個人で楽しむ範囲を超えてネットに再配布することになります。画像は自分のPCの `public/local/` にだけ置いて使います(git 管理外)。
- **辛口が向くのは、遊んでいる本人だけ。** 暴言まじりの口ぐせも入っていますが、向く先は入力した Riot ID の成績だけです。ほかの実在の人の名前、死や暴力を願う言葉、容姿・性別に触れる文は入れていません。最後の「次の宿題」は具体的な助言にしています。
- **公開しない・広めない。** 開発サーバーは `127.0.0.1` にだけ開き、共有ボタンはなく、ページは `noindex` です。自分のアカウントで遊び、結果をご本人の発言であるかのように広めたり、ほかの人をからかう目的で使ったりしないでください。
- **APIキーをブラウザに渡さない。** キーは開発サーバー(Node 側の `server/`)だけが持ち、ブラウザには本人の成績だけを抜き出した結果を返します。ほかの9人の情報は画面に届きません。
- **Riot API を叩きすぎない。** 1回の検索で約44回(アカウントなど4回+試合20回+タイムライン20回)呼びます。開発用キーは2分で100回までなので、続けて3人目を調べると制限にかかります。同じIDの結果は5分間メモリに持ち、回数制限(429)には待ってからやり直し、タイムラインが取れなかった試合はそのぶんの解析だけを省きます。

## 写真・ロゴ・口ぐせを足す

`lol/public/local/` に次のファイルを置くと、ページを再読み込みするだけで反映されます。このフォルダの中身は git に入りません。

| ファイル名 | 使われる場所 |
| --- | --- |
| `critic.png`(`.jpg` `.jpeg` `.webp` でも可) | 評価役の名前の横に出る丸いアイコン |
| `logo.png`(`.jpg` `.jpeg` `.webp` でも可) | 「③ 辛口評価」の見出しの横に出るロゴ |
| `phrases.json` | 自分で足す口ぐせ |

口ぐせは `public/local/phrases.example.json` を `phrases.json` という名前でコピーして書きます。評価の冒頭・認めるとき・却下するとき・追加の指摘・総評・宿題の7か所に分けて並べ、口ぐせがある場所では毎回ひとつ付きます。同じ言い回しは1回の評価で1度しか使わないので、たくさん入れるほど口ぐせの付く吹き出しが増えます。書き方の詳細は [public/local/README.md](public/local/README.md) にあります。

### コードに入っている口ぐせ

`src/phrases.ts` に、のべ約230件(同じ言い回しを複数の場所に置いたぶんを含む。言い回しの種類は約210、うち言い回しを一部改変したものが24件)入っています。

- **出どころ**: ほとんどは、視聴者がまとめたスプレッドシート「[らいさまちくちく集](https://docs.google.com/spreadsheets/d/1txzsWYmA86n7yrMtovgvI1arzblxUIG0DFLLcNi4lnU)」(発言とクリップへのリンクの一覧、1,135件)から選びました。全件を読み、表記はシートのとおりにしています。1件ごとにシートの No. を `source` に書いてあります。クリップそのものは確かめていないので、聞き取りの正しさはシートを作った方々に頼っています。
- **シート以外**: 「TOPレーナーとしてどうかと思う。」「このチーム弱ｗ」「最も替えたくなかったのがサポートだった。」は記事の題、「負けてる時のことは考えなくていいから、負けるな。」は検索結果の引用が根拠です(最後の1件は表記未確認)。
- **暴言はそのまま**: 遊ぶ本人が望んだ辛口なので、「バカ」「カス」「雑魚」「ゴミ」のような暴言はそのまま入れています。
- **名指しの発言は加工**: ほかの実在の人の名前は入れていません。名指しの発言は、名前を遊んでいる本人の名前に置きかえるか(例:「{name}がほんとに下手！ｗ」)、名前のところを省いて入れ、`source` に「名前を置きかえ」「名前を省略」「抜粋」と書いています。
- **自然につながるように一部を改変**: 口ぐせは評価文の前後に付くので、そのままではつながらないものは言い回しを少し変えています(複数形を単数に、その場面に固有の語を省く、「ただ、」のようなつなぎを足す)。たとえば「ビジョン取りおくんです」→「ビジョン取りおくんじゃん」、「このチーム弱ｗ」→「この人弱ｗ」、「操作が下手なのはしょうがない」→「操作が下手なのはしょうがない。ただ、」。変えたものは `source` に「言い回しを一部改変」と書いてあり、意味を変える書きかえはしていません。
- **場面に合わせた出し分け**: 1件ずつ、合う話題・ロール・評価を決めています。「TOPなんだからさぁ、」のようなロールの話はプレイそのものへの指摘にだけ、「操作が下手なのはしょうがない。ただ、」は連戦や降参など操作以外の指摘にだけ、というように付く場所を限っています。
- **入れていないもの**: ほかの実在の人の名前、性別をけなすもの、揉め事に由来する発言、ほかの人の発言。テストでも検査しています。
- **過激なものは別にしてある**: 死や暴力を願う言葉(「しね」など)と見た目へのいじりは、`src/extreme-phrases.ts` に分けてあり、最初は出ません(下の「過激な口ぐせ」)。
- **評価による出し分け**: 「久しぶりに見たな頭おかしくなってるやつ」「終わっとるやんけ！」のようなきつい言い回しは、総合評価が C・D の人にだけ出します。皮肉まじりの褒め方は S・A の人には出しません。
- **話題とロール**: 「本当にファームが下手」はCSの指摘に、「なんでワードない？」は視界の指摘に、というように、話題の合う口ぐせを先に使います。「TOPレーナーとして…」「このクソJGマジで」のようなロール限定のものは、そのロールの人にだけ出ます。

### 追加の口ぐせ(場面が固有のもの・長いもの・雑談)

同じシートから、さらに約310件を `src/phrases-extra.ts` に入れています。評価文にきれいにはつながらないものが多いので、扱いを分けています。

- **脱線**: LoL と関係のない雑談(「俺、犬派なんだよね」「トイレを流せ！」)、長い台詞、使っているチャンピオンの話は、評価文には付けず、③ の中の「脱線」という独立した吹き出しで出します。1回の評価につき2つまでです。
- **チャンピオンの話は、使っている人にだけ**: 直近の試合でそのチャンピオンを使った人にだけ出します(ヤスオを使った人に「お前がやってるのはヤスシ。ここにいるのはヤスオ」、ナサスを使った人に「ナサス使っててスタックにこだわってる奴はBAKA」など、約40件)。
- **スキルやウルトの話**: 「ウルト！おい！」「だからRW撃つなつってんだろ」のような、その場面の話は、プレイへの指摘に混ぜます。成績の数字と話がずれることがありますが、それも込みで楽しむ前提です。
- 表記はシートから機械的に写しています。決まり(ほかの実在の人の名前を入れない、など)は上と同じです。

### 過激な口ぐせ(自分でチェックを入れたときだけ)

`src/extreme-phrases.ts` の32件は、③ の下の「過激な口ぐせも混ぜる」にチェックを入れたときだけ出ます。最初はオフで、ブラウザが覚えます。

- 死や暴力を願う言葉(「しね。しねしねしね」「ボタン全部押して死ね」など)と、見た目へのいじり(「デブに救いはないよ、ないない」「お前だ、メガネ」など)です。見た目へのいじりは成績と関係なく、脱線として飛んできます。
- 分けてある理由は、自分以外の Riot ID を見たときや、写真つきの画面をほかの人に見せたときに、そのまま出ないようにするためです。自分の成績を自分で見るときにだけ入れてください。
- ここにも入れていないもの: ほかの実在の人の名前と、性別をけなす台詞(「女が悪い」の類)。遊んでいる本人へのいじりではなく、ある性別の人みんなをけなす内容になるためです。

### 言いそうな台詞(創作)

実際の発言とは別に、話し方の傾向から連想して作った口ぐせを `src/imagined-phrases.ts` に約145件入れています(「負けてすぐキュー押すのやめな？ マジで」「寝ろ。マジで寝ろ」「ドラゴン寄って。ドラゴンドラゴンドラゴン」など)。**ご本人が実際に言ったものではありません。**

- 実際の発言(`phrases.ts`)とは必ずファイルを分け、1件ごとに「創作」と書いています。同じ文を両方に入れないことも、テストで検査しています。
- もとにした傾向は、「…まあいいや」で話を投げる、同じ言葉の連呼、「〜なんだよね」「マジで」「普通に」での締め、「〜でーす」という丁寧語の皮肉、「えらいえらい」「〜おいちい」という褒め方、などです。
- 連戦・深夜・降参・「?」ピンなど、実際の発言が見つからなかった話題を主に埋めています。実際の発言と並ぶところでは実際の発言が2倍出やすく、話題に合うのが創作だけのところでも、2回に1回は実際の発言に出番をゆずります。
- ③ の下の「言いそうな台詞も混ぜる」のチェックを外すと、口ぐせは実際の発言として記録のあるものだけになります(ブラウザが覚えます)。
- 入れないものの決まり(ほかの実在の人の名前、死や暴力を願う言葉、容姿・性別に触れるもの)は、実際の発言と同じです。

## 採点の仕組み

- ロールごとに「悪い〜良い」の目安を置き、あいだを直線で 0〜100 点にします(`analyze.ts` の `BENCH`)。厳密な統計ではなく、ふつうなら50点前後になるように置いた値です。CS・視界・ダメージ割合などロールで基準が変わる項目は、メインロールの試合だけで見ます。サポートはCSを採点しません。
- 総合点は6軸の平均が9割、勝率が1割です。80点以上がS、67点以上がA、54点以上がB、41点以上がC、それ未満がDです。
- **くわしい解析**(`detail.ts`)では、次のものを出します。
  - 対面(相手チームの同じロール)との差: 10分・15分のゴールド差、10分のCS差、レーンではっきり差をつけた試合の割合
  - デスの内訳: 序盤・中盤・終盤の割合、相手の陣地でのデス、1対1でやられたデス(タイムラインから)
  - 条件別の勝率: 青側/赤側、試合の長さ、始めた時刻、直近5試合、負けた直後に始めた試合、15分でリード/ビハインドした試合
  - 最長の連戦、降参で終わった負け、「?」ピンの数、オブジェクト関与の割合、試合ごとの出来(0〜100)
- 強みは22種類、弱みは28種類あります。くわしい解析からは「15分でいつも負けている」「10分までに死にすぎる」「リードした試合を落とす」「負けた直後に続けて負ける」「深夜に負けが込む」「すぐ降参する」「勝てないチャンピオンを使い続ける」などを拾います。条件は `analyze.ts` にあります。
- 自己紹介は、はっきり出ている強みから最大3つ。足りないぶんは弱みを強気に言い換えて埋め、評価役がそれを数字で崩します。強みは認めたうえで、関係する弱みがあれば「ただし」を足します。
- 文章は Riot ID から決まる種で選ぶので、同じ人なら同じ結果になります。「言い直してもらう」を押すと、言い回しだけでなく、取り上げる強み・弱み、称号、宿題の顔ぶれも変わります(最初はいちばん目立つもの、言い直すたびに、はっきり度を重みにした抽選)。
- 文の候補は `src/text/` に、合わせて約1,900件あります(自己紹介が約500件、評価が約1,400件)。話題ごとに、強みの自慢は9つ、弱みの言い換えは8つ、認める返事は9つ、崩す返事は8つ、追加の指摘は9つ、宿題は5つ、称号は7つ。強みを認めたあとの「ただし」は180組あります。候補を足せば、そのぶんバリエーションが増えます。サンプルで200回言い直して、同じ文章が一度も出ないことをテストしています。
- 文の数だけでなく、組み立て方にも変化をつけています(`src/text/note-lines.ts`)。
  - 自己紹介の2つ目・3つ目の前に、つなぎの言葉(「それと、」「さらに言うと、」など)が入ることがあります。
  - 自己紹介の最後に、いちばん良かった試合を自分から自慢し、評価役がそれに返します。
  - 評価の終わりに「ところで」として、強みや弱みと言うほどではないが目に付いた数字(サイド別の勝率、連戦の長さ、試合の平均の長さ、勝った直後の勝率など)に触れます。もう弱みとして話に出たことは繰り返しません。
  - 言い直すと、称号に枕ことば(「筋金入りの」「自称・」「正真正銘の」など)が付くことがあります。
- この表の文(評価の中身)には、罵倒語や実在の人の名前を入れていません。評価役らしい言い回しは、口ぐせの表(`phrases.ts` と `imagined-phrases.ts`)が前後に足します。
- AI(LLM)は使っていません。入れる場合は、APIキーをブラウザに置かず `server/` 側を経由させてください。
