# 手元にだけ置く素材

このフォルダの中身は、この README と `phrases.example.json` を除いて **git に入りません**(ルートの `.gitignore`)。
ご本人の写真やロゴは著作権・肖像権のあるものなので、公開リポジトリには入れず、自分のPCのこのフォルダにだけ置いて使います。

| ファイル名 | 使われる場所 |
| --- | --- |
| `critic.png`(`.jpg` `.jpeg` `.webp` でも可) | 評価役の名前の横に出る丸いアイコン |
| `logo.png`(`.jpg` `.jpeg` `.webp` でも可) | 「③ 辛口評価」の見出しの横に出るロゴ |
| `phrases.json` | 自分で足す口ぐせ。書き方は `phrases.example.json` をコピーして直す |

置いたらページを再読み込みするだけで反映されます(無ければ何も出ません)。

## 口ぐせの足し方

`phrases.example.json` を `phrases.json` という名前でコピーし、場所ごとに言い回しを並べます。

| 場所 | 使われるとき |
| --- | --- |
| `opening` | 評価の最初のひとこと |
| `accept` | 自己紹介を「認める」とき |
| `reject` | 自己紹介を「却下」するとき |
| `roast` | 自己紹介になかった弱みを指摘するとき |
| `verdictHigh` | 総評(S・A) |
| `verdictLow` | 総評(B・C・D) |
| `homework` | 次の宿題を出すとき |

- 口ぐせは評価文とそのままつながります。文として言い切るもの(「下手だな」)は句点が自動で入り、「あとさぁ、」のように読点で終えると、そのまま次の文に続きます。
- 文字列をそのまま書くと、評価文の**前**に付きます。**後ろ**に付けたいときは `{ "text": "…", "after": true }` と書きます。
- `{name}` と書くと、プレイヤー名に置きかわります。
- 1つの言い回しは80文字まで。同じ言い回しは1回の評価で1度しか使わないので、たくさん入れるほど口ぐせの付く吹き出しが増えます。
- `{ "text": "…", "role": "TOP" }` と書くと、メインロールがそのロールの人にだけ使います(`TOP` `JUNGLE` `MIDDLE` `BOTTOM` `UTILITY`)。
- `{ "text": "…", "topic": "lowcs" }` と書くと、その話題の評価文にだけ使います。`"topic": ["feeder", "earlydeath"]` のように複数書くと、そのどれかに使います。話題の名前は次のとおりです。
  - 弱み: `feeder`(デスが多い) `grayscreen`(死んでいる時間が長い) `lowcs`(CSが少ない) `loselane`(10分CSが少ない) `blind`(視界が少ない) `nopink`(コントロールワードを買わない) `afk`(キル関与が低い) `lowdamage`(ダメージが少ない) `kdaplayer`(KDAは高いのに勝てない) `coinflip`(試合ごとの波が大きい) `tourist`(チャンピオンを使いすぎ) `losing`(勝率が低い) `nomad`(ロールが定まらない) `noobjective`(オブジェクトに絡まない)
  - 強み: `kda` `cs` `vision` `teamfight` `damage` `solokill` `survive` `objective` `onetrick` `winrate` `firstblood` `pool` `multikill`
- `{ "text": "…", "grades": ["C", "D"] }` と書くと、総合評価がそのどれかの人にだけ使います(`S` `A` `B` `C` `D`)。きつい言い回しを高評価の人に出したくないときに使います。
- コードに入っている口ぐせ(`src/phrases.ts`)と同じ言い回しを書いても、二重には出ません。
- 実際に聞いたことのある言い回しだけを入れてください。言っていないことを「言った」ことにしないためです。
